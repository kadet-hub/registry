Change the target, watch both islands

The target sets bucket and region once. Both generators read them, so the same values arrive in a ConfigMap and in Terraform JSON.

inventory/targets/prod.yml

classes: [generators, uploads]parameters:  bucket: example-shop-uploads-prod  region: eu-central-1

3 to 63 characters: a letter first, then lowercase letters, digits and hyphens, no hyphen last, and no YAML keyword such as true or null. The excerpts keep the last value that fits.

The class generators pins both generators by version and digest, as station 1 lists them. kadet-hub's consumer workflow verifies both before it fetches them.
