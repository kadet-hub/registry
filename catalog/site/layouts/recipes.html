Rebuilt from a Helm chart, a release manifest or a Docker Compose file, or designed on an image

From kadet-hub/recipes. Its CI compares each chart recipe with the chart or release manifest it rebuilds. At level renders it compares the objects and permissions, at deploys it also installs the recipe on kind and runs its smoke test. A compose file has no objects to compare with, so a compose recipe is at deploys and proven by the install and its smoke test alone. So is a recipe designed in kadet-hub on the image of a project that ships neither.
