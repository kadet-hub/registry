How a version gets listed

How kadet-hub works follows the whole process with diagrams, from the pull request to your compile.

Scanned

The gate scans the generator's source for leaked secrets, malware patterns and risky code before anything runs. A finding fails the pull request that registers the version.

Compiled in a sandbox

Its fixture targets compile in a gVisor sandbox without network, on every inventory backend it declares and again with Kapitan's cache. The output is validated against the shipped JSON Schemas and dry-run against a throwaway kube-apiserver with the operators' own CRDs.

Reviewed, signed and pinned

A maintainer reviews the gate report. The version is published as an OCI artifact with a Sigstore signature, an SBOM and a transparency log entry, and you pin it by digest in your inventory. How to consume a generator.
