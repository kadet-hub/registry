Kubernetes kinds

Every Kubernetes kind of the generators' latest listed versions, by API group. "Rendered by" names the generators whose fixture output renders the kind, as the release recorded it. "Schema shipped by" names generators whose latest listed version was published before the release recorded kinds; their kinds come from the JSON Schemas they ship, with the kind in lower case as in the file names. A kind that two or more generators render has its own page. Kubernetes built-in APIs are the groups kube-apiserver serves without CRDs; another group shows its software where the generators' schema records name one. core is the core group, apiVersion v1; a section named by a version, such as v1alpha1, holds kinds whose apiVersion has no group.
